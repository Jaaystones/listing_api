
## About the job

**About Expert Listing**

Expert Listing is a Nigerian proptech platform that connects people with verified agents, developers and property owners across Lagos, Abuja and beyond. Our promise: find your preferred property in 3 clicks, not months. We're looking for a Senior Backend Developer to own and scale the APIs behind our web and mobile apps.

**What you'll do**

* Design, build and maintain secure, high-performance APIs for listings, search, messaging, subscriptions and payments
* Own database design and query performance as listings and traffic grow
* Build integrations with payment gateways, maps and location services, notifications and third-party services
* Set up testing, code reviews and good engineering habits across the team
* Work closely with the frontend, mobile and product teams

**What we're looking for**

* 5+ years of backend development experience, with production systems you can point to
* Strong skills in at least one modern backend stack (Node.js/TypeScript, Python, Go or similar)
* Solid experience with relational databases (PostgreSQL/MySQL), caching and REST or GraphQL API design
* Familiarity with cloud deployment, CI/CD and containers
* Nice to have: search engines (Elasticsearch/Meilisearch), geospatial queries, marketplace or proptech experience

**Short task (about 3–4 hours; submit within 72 hours)**

Build a small Property Listings API with:

1. CRUD endpoints for listings (title, price, type: rent/sale/shortlet, bedrooms, location with lat/lng, agent ID)
2. A search endpoint that filters by type, price range and bedrooms, and returns listings within X km of a given point
3. Pagination, input validation and sensible error handling
4. At least a few unit or integration tests
5. A README explaining setup, your design choices and what you'd improve with more time
